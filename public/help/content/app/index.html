The standard application functions

This book will describe the everyday functions of Veeto for the people who use it in their firm: matters, contacts, documents, invoices, time billing and so on.

Not written yet. The system administration book is complete. This one is a place held for the application's own help, and has no topics so far.

Where the topics will go

Each topic becomes one page in this book, grouped under a section heading in the menu on the left. The sections below are suggestions to start from and can be changed.

  • Getting started: signing in, your password, the screen layout
  • Matters: opening a matter, the Matter Summary tab, status, the Workflow tab
  • Contacts and documents: contacts, attachments, precedents
  • Money: invoices, time billing, payments
  • Administration inside a firm: users, roles, sites, settings
  • Reference: messages, troubleshooting, glossary

Adding a topic

Adding a page takes two steps: write the page, and list it in the menu. The full steps are in Adding to the help.
