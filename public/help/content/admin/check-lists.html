Check lists

A check list is an ordered set of tasks. It is what a matter's Workflow tab is built from.

How the four parts fit together

The company page's Checklists tab has four sub tabs, the same four the company has in its own Admin menu:

Check listsNamed lists that gather tasks in order.This page
TasksThe individual tasks, each with optional sub tasks.Tasks

The list

Each row shows the check list's name (with its description underneath) and how many tasks it holds. Search finds a check list by name, or by the title of one of its tasks.

Adding a check list

  1. Open the Check lists sub tab and choose Add check list.
  2. Type the Name (required) and, if you like, a Description.
  3. Under Tasks, in order, choose Add a task for each row. In each row:
    • Choose an existing task, or New task… and type its title.
    • Optionally choose a Group (or No group).
    • Tick Required if the task must be completed.
    • Use the move up and move down buttons to set the order, or Remove to take the row out.
  4. Choose Save.

Within each group the tasks keep the order shown in the form. A check list needs at least one task, and every row needs a task.

Editing a check list

Choose Edit, change the tasks or their order, and choose Save. Saving a check list does not rename a task that already exists.

Saving a check list does not change matters that already use it. To pass the change on, sync the check list (below).

Syncing changes to matters

  1. Choose Sync on the check list's row.
  2. Choose who receives the change:
    • Matters that already have this check list, or
    • Every matter linked to it, giving the check list to those without one.
  3. Choose Sync. A progress bar counts through the matters in batches until it is complete.

When it finishes you see totals: how many matters were given the check list, how many were updated, how many tasks were added, removed, moved or renamed, and how many tasks were kept because they were already under way. Choose Close when done.

Deleting a check list

Choose Delete and confirm. A check list that is linked to a matter type cannot be deleted: unlink it first on the Link to matter sub tab. If it is still in use you are told That is still in use.
