Creating a company

Set up a new firm in one go: its details, its sites, its roles and its first administrator. Everything is created together, or none of it is.

To create a company

  1. Choose Companies, then Create company.
  2. Fill in the four parts of the form (below).
  3. Choose Create company at the bottom.
  4. A window shows the first administrator's temporary password. Copy it and give it to them: it is shown only this once.

1. Company

The firm's name (required), address, contact details, DX details and disclaimer. These can be changed later on the Details tab.

2. Sites

A site is one office. Records, staff and numbering are kept per site. The first site is where the administrator is based, and it must be active.

  • Give each site a name (required), and optionally a code, ABN, email, website and time zone.
  • GST rate: leave it blank and the company must set it itself before it can invoice.
  • Financial year starts: choose a day and a month, or leave both blank for 1 July to 30 June. The end date is worked out for you.
  • Choose Add another site for each further office. Remove takes one off the form.

More about these fields in Sites.

3. Roles

Choose how the company's roles start:

  • One Administrator role with every right. The company can add more roles itself afterwards.
  • Define the roles now. Add each role with a name, description and the rights it grants.

You can also copy the roles of an existing company. Each role is copied with its rights and its billing tier; a role with the same name as one you defined is skipped.

4. First administrator

This person is created as a staff member at the first site, with access to every site you listed.

  • Username (required): 3 to 100 letters, numbers or the symbols . _ @ + -. It must not already be used by anyone.
  • First name and Last name (required), Email (optional).
  • Role: which of the roles above they hold.
  • Temporary password (optional): 8 to 20 characters. Leave blank to have one generated.

They must choose their own password the first time they sign in to Veeto.

After it is created

  • The company appears in the companies list and its page opens.
  • The standard billing rates are not set for a new company. Set them before generating a cost record.
  • The company's checklists, numerals and storage start empty. Set them on the company page, or let the company do it.
  • The creation is recorded in the audit log (COMPANY_CREATED).

If anything is wrong (a missing name, a username already taken), nothing is created and the form tells you what to fix. You will not be left with half a company.
