Messages and what they mean

The messages the portal can show you, what causes each one, and what to do.

Signing in and accounts

CodeMessageWhat to do
500090The system admin portal is not enabled on this server.The portal is switched off in the server's configuration. Ask whoever runs the server.
500091Invalid username or password.Check both and try again. The same message is shown for an unknown username and a wrong password.
500092This account is locked. Try again later or ask another system admin.Wait 15 minutes, or ask another admin to unlock it. See System admins.
500093A system admin password needs at least 12 characters, with upper and lower case letters, a number and a symbol.Choose a stronger password. See Your account.
500094That username is already taken.Choose another username.
500095That system admin could not be found.They may have been removed. Reload the list.
500096That would leave no active system admin, so nobody could sign in to the portal.Add or unlock another admin first.
500097You cannot do that to your own account. Ask another system admin.Ask a colleague, or use Account to change your own password.
500098The current password is not correct.Retype your current password.

Companies, sites, roles and users

CodeMessageWhat to do
500099That company could not be found.Go back to the companies list.
500100The request is missing something required or is not valid.Check the form: a required field is empty, or a value is outside its allowed range.
500101That site could not be found in this company.Reload the page. A site can be chosen only from the company you are working in.
500102That role could not be found in this company.Reload the page and choose a role again.
500103That role is still assigned to users, so it cannot be deleted.Move its users to another role first. See Roles.
500104That user could not be found in this company.Reload the page.
500116That staff member could not be found in this company.Reload the page.

Matter types

CodeMessageWhat to do
500105That matter type or sub type could not be found.Reload the page.
500106A matter type or sub type with that name already exists.Choose a different name.
500107That matter type or sub type is still used by matters, templates or settings, so it cannot be removed.It can be renamed but not removed while it is in use. See Matter types.
500108The application relies on that matter type or sub type, so it can be renamed but not removed.It is one of the protected types. Rename it if you need to.
500034Please provide a valid Matter Type-SubType Identifier!Choose a type and sub type that exist together. Reload the page if the list is out of date.

Check lists

CodeMessageWhat to do
500117That checklist item could not be found in this company.Reload the page.
500118That is still in use (a task in a check list, a check list linked to a matter type, or a group with tasks in it), so it cannot be deleted.Take it out of its check list, or unlink it, first. See Check lists.

Billing

CodeMessageWhat to do
500110Set the rate for every user tier this company has users on before generating a cost record.Set the missing rate on the company's Billing tab. See Setting rates and tiers.
500111A rate must be a number from 0 to 100000 with at most two decimal places.Correct the rate.
500112Choose a month that has started: not before 2000 and not in the future.Pick another month.
500113That cost record could not be found.It may have been deleted. Go back to the Billing page.
500114That cost record has been finalised, so it can no longer be regenerated or deleted.A finalised record is permanent. See Cost records.
500115The tier must be STANDARD or POWER.Choose Standard user or Power user.

If you see a message that is not listed here, or a general error, see Troubleshooting.
