Storage type

Where one site keeps its documents: on the server, or in the company's own OneDrive.

What the tab shows

Choose the site, then read the table of setups that site has.

ColumnMeaning
StorageThe server, OneDrive or Google Drive.
CategorySpecific or General (OneDrive only).
DetailsFor OneDrive: tenant, client, whether a secret is held (the secret itself is never shown) and the folder.
StatusIn use or Not in use. Only one setup is in use at a time.

To change the storage

  1. Open the company's Storage tab and choose the site.
  2. Either choose Use this setup on an existing row, to fill the form from it, or start from the form.
  3. Under Store documents on, choose The server or OneDrive.
  4. For OneDrive, fill in:
    • Category: Specific or General.
    • Organisation folder.
    • Tenant ID, Client ID, Client secret and SharePoint site ID (all required). If a secret is already held, leave Client secret blank to keep it.
  5. Choose Save storage type, then confirm.

The confirmation reads: This only changes the setting: it does not move any document that is already stored. Documents already saved stay where they are. Plan any move separately.

Google Drive

Google Drive uses one platform account, so it has no setup here. If a site already uses it, it appears in the table.

Each change is recorded in the audit log (STORAGE_UPDATED). Secrets are never written to the log.
