Matter types and sub types

The matter types and sub types every company uses. A change here reaches every company at once.

Matter types are shared by all companies. Something you add, rename or remove here changes what every company sees. A new type or sub type appears in the application when users next sign in or reload.

Two tabs

  • Matter types: the types themselves, with the sub types offered under each and where each is in use.
  • Sub types: the sub types, with the types they are offered under, the tabs a matter shows and any extra statuses.

Each tab shows how many there are in its label, and has a search box (by name or code) and a Add matter type or Add sub type button. The In use column says what relies on each, or Not used.

Adding a matter type

  1. On the Matter types tab choose Add matter type.
  2. Type the Name.
  3. Tick the sub types offered under this type.
  4. Choose Save.

The code kept on matters is made from the name when you first save it and cannot be changed later. Matters store the code, not the name, so renaming a type never changes a matter.

Adding a sub type

  1. On the Sub types tab choose Add sub type.
  2. Type the Name.
  3. Under Tabs a matter of this sub type shows, tick any extra tabs. Matter Summary, Contacts, Attachments, Invoices and Time Billing are always shown.
  4. Under Extra statuses, tick any you want. Instructed, In Progress, Not Proceeding and Complete are always offered.
  5. Under Offered under these matter types, tick the types it belongs to.
  6. Choose Save. A message confirms Saved.

Editing

Choose Edit on a row. You can rename it and change what it is offered under. Unticking a sub type from a type is refused while a matter, contact role or check list uses it under that type.

Removing

Choose Remove and confirm. You can remove a type or sub type only when nothing uses it. If it is in use the button is disabled and its hint says why.

  • That matter type or sub type is still used by matters, templates or settings, so it cannot be removed.
  • The application relies on that matter type or sub type, so it can be renamed but not removed. This applies to the protected types: General, Revenue NSW, VOI Client Authorities, Conveyancing, Business Sale/Purchase and Family Law.

Other messages

  • A matter type or sub type with that name already exists. Choose a different name.
  • That matter type or sub type could not be found. It was removed by someone else. Reload the page.

Every change is recorded in the audit log (for example MATTER_TYPE_CREATED). The list of types and sub types is what the Link to matter tab uses.
