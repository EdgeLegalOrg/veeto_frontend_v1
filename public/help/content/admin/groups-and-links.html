Task groups and linking to matters

Groups arrange the tasks in a check list under headings. Links decide which check list a new matter starts with.

Task groups

The Task groups sub tab lists each group with its description and its order. Groups show lowest order first. Search finds a group by title.

Adding or editing a group

  1. Choose Add task group, or Edit on a group's row.
  2. Type the Title (required) and a Description if you like.
  3. Set the Order: a whole number. Lower numbers show first.
  4. Choose Save.

An icon for a group can be set from the company's own Task Groups screen, not from here.

Deleting a group

Choose Delete and confirm. A group that has tasks in a check list cannot be deleted. You are told That is still in use.

Link to matter

The Link to matter sub tab lists every matter type and sub type with a menu for its Check list.

  1. Find the type and sub type (search by matter type or check list).
  2. Choose a check list from its menu, or None to remove the link.

It saves at once and a message confirms Linked or Link removed.

A matter created from a linked type and sub type is given that check list. Matters that already exist are not changed until you sync the check list.

The list of matter types and sub types comes from Matter types.
