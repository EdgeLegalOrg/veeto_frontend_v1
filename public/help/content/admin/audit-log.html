Audit log

Every sign-in and every change made in this portal, newest first. It cannot be edited from here.

The columns

ColumnMeaning
WhenThe date and time.
AdminThe system admin who did it.
ActionWhat was done, as a code (see below).
TargetWhat it was done to: a company, a site, a role, a system admin and so on.
DetailA short description. Passwords and secrets are never written here.
FromThe network address the request came from.

Finding entries

  • The search box looks in the admin, action, target, detail and address.
  • From and To limit the list to a range of dates. If From is after To, the dates are ignored and the page says so.
  • Clear all removes the search and the dates.

See also Searching and paging lists.

Exporting

  1. Set the search and dates so the list shows what you need.
  2. Choose Export, then Excel (.xlsx) or CSV (.csv).
  3. The file downloads. A message tells you how many rows it holds.

The file holds every row that matches the search and dates, not just the page you are looking at. Its columns are When, Admin, Action, Target type, Target id, Detail and From.

An export holds at most the newest 20,000 matching rows. If there are more, the message says Exported the newest 20000 rows. Narrow the dates to export the rest. Export in date ranges to get everything. If nothing matches, you are told there is nothing to export.
