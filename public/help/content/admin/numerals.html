System numerals

The range each kind of number is drawn from, for one site.

The numbers you can set

  • Matter numbers
  • Archived matter numbers
  • Packet numbers
  • Invoice numbers
  • Payment numbers

To set a range

  1. Open the company's Numerals tab and choose the site. Numbers are kept per site.
  2. For each kind of number you want to control, tick Use a range.
  3. Type where it starts in From and where it ends in Up to.
  4. Choose Save numerals. A message confirms System numerals saved.

The rules

  • Use whole numbers from 0 up, with up to 9 digits.
  • When Use a range is ticked, From must be 1 or more, and Up to must be the same as or after it.
  • When it is not ticked, numbers carry on from the highest already used.

The numbers already used are not checked here. If a range ends below the highest number in use, the application reports that series as used up when someone next needs a number. Set Up to above anything already issued.

Each save is recorded in the audit log (NUMERALS_UPDATED).
