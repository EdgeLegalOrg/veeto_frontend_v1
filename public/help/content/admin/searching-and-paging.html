Searching and paging lists

Every list in the portal works the same way: type to search, and use the page controls at the foot to move through long lists.

Searching

  • Type in the search box above the list. The list narrows as you type: you do not need to press Enter.
  • Searching goes back to the first page.
  • The search is not case sensitive.
  • Choose Clear beside the box to show everything again.

The box tells you what it searches. For example, the companies list searches name, city, state and number; the staff list searches name, email, phone and login.

Paging

At the foot of each list:

  • Showing 1 to 20 of 134 tells you where you are.
  • Previous, the page numbers and Next move between pages. A long list shows the first and last pages and those near the current one, with a gap (…) between.
  • The rows per page menu offers 20 (the default), 50 and 100. Changing it goes back to the first page.

If the list gets shorter while you are on a later page, because rows were removed or you narrowed the search, you are taken to the last page that still exists rather than shown an empty page.
