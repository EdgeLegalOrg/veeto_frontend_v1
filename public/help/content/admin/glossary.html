Glossary

The words used in the portal and in this help.

System admin
A person who can sign in to this portal. They belong to no company and are separate from a company's own users. See System admins.
Company
One firm using Veeto. Its sites, roles, users, staff and settings are kept apart from every other company's.
Site
One office of a company. Records, staff, numbering and storage are kept per site. See Sites.
Role
A named set of rights that a user holds. It also decides the user's billing tier. See Roles.
Right
One permission that a role can grant in the application. Rights are grouped by category when you edit a role.
User
A login to the application. See Users.
Staff member
A person who works at a company's site, with or without a login. See Staff.
Temporary password
A one-time password given to a new or reset user, who must replace it at first sign-in. See Temporary passwords.
Credentials version
A counter on each system admin that goes up when their password changes, so that older sign-ins stop working.
Lock
Stopping a login from being used, without deleting it. An account can be locked by another admin, or by five wrong passwords.
Matter
A piece of work for a client, kept as a record in the application.
Matter type and sub type
How matters are classified, for example a type and a sub type under it. Shared by every company. See Matter types.
Check list
An ordered set of tasks that a matter's Workflow tab is built from. See Check lists.
Task, sub task
A step in a check list, and a smaller step within it. See Tasks.
Task group
A heading that gathers tasks in a check list. See Task groups.
Sync
Passing a check list's current tasks on to the matters that use it.
System numerals
The number series (matters, invoices and so on) and the range each is drawn from, per site. See System numerals.
Storage type
Where a site keeps its documents: the server, OneDrive or Google Drive. See Storage type.
Billing tier
Standard user or Power user. A role is put on a tier, and each tier has its own monthly rate per company. See How billing works.
Rate
The dollars charged per user per month for a tier, set per company.
Cost record
A snapshot of one company's users and charges for one month. It is a draft until finalised. See Cost records.
Draft, Finalised
A draft record can be regenerated or deleted. A finalised record is kept exactly as it is.
Audit log
The record of every sign-in and change in the portal. See Audit log.
Session
One period of someone being signed in to the application. See Logged in users.
