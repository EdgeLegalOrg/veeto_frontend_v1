Tasks

The individual steps that check lists are made from, each with optional sub tasks.

The list

The Tasks sub tab shows each task's title (with its description underneath) and how many sub tasks it has. Search finds a task by title.

Adding a task

  1. Open the company's Checklists tab, then the Tasks sub tab, and choose Add task.
  2. Type the Title (required) and a Description if you like.
  3. Choose Add sub task for each sub step. For each one, type its title, and tick Required if it must be completed. Remove takes one out.
  4. Choose Save.

Editing a task

Choose Edit, make the change and choose Save. A message confirms Task saved.

Deleting a task

Choose Delete and confirm. A task that is in a check list cannot be deleted: take it out of the check list first (see Check lists). If it is still in use you are told That is still in use.

You can also create a task while building a check list, by choosing New task… in a row.
